Ghép cặp gateway (mã do admin phát)

Tạo mã → đọc/gửi cho người lắp đặt → họ nhập vào GatewayApp (trang Cloud). Gateway gửi toàn bộ thiết bị + setting + UI lên đây; bạn xem trước, đặt site/mã tem rồi Duyệt & tạo QR. Gateway không tự đăng ký được nếu thiếu mã.

Thêm thiết bị (QR in tem)

Nhập một lần tại đây (site / mã tem / seed). Server tự cấp MQTT. Gateway MCU/C# gọi POST /api/v1/gateway/enroll với cùng QR — không hard-code broker/pass/danh sách con. User điện thoại vẫn quét QR để claim.

Thiết bị sau gateway (type trên server → UI)

Gateway chỉ publish số d.{childId}.{field}. Type chọn ở đây để app dựng widget / monitor / control.

Kích hoạt gateway

Có internet (phổ biến): không cần làm gì ở đây. Gateway gửi ID máy khi nạp cấu hình (enroll kèm hw); server tự gắn tem với máy đó ở lần đầu, máy khác dùng lại tem sẽ bị từ chối. Muốn chuyển sang máy mới: bấm "Gỡ máy đã gắn" ở danh sách thiết bị bên dưới.
Không internet (chỉ có mạng LAN): gateway có ô nhập khoá như phần mềm thông thường. Chọn thiết bị, nhập ID máy, bấm tạo — gửi khoá 20 ký tự cho khách gõ vào. Khoá chỉ đúng cho máy có ID đó.

Sản xuất: lấy khoá nạp cho máy mới

Mỗi gateway cần một khoá riêng, nạp vào chip lúc sản xuất (không để lộ). Nhập ID máy (4–40 chữ và số) rồi lấy khoá; bấm "Tạo ID mới" nếu chưa có.

Token cho tool nạp gateway

Tool GatewayProvisioner trên PC sản xuất dùng token này để gọi VPS. Token chỉ hiện một lần khi tạo — hãy chép ngay vào tool. Mất máy hoặc nghỉ việc thì thu hồi token tại đây.
